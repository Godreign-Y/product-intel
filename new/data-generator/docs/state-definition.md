# STATE DEFINITION

## Purpose

Represents the complete business state of a product on a given day.

State is divided into:

1. Static Context
2. Controllable State
3. Market State

---

# Static Context

These never change.

```json
{
  "product_id": "string",
  "category": "string",
  "subcategory": "string",
  "brand": "string"
}

---

# Controllable State

Management can directly modify these.

```json
{
  "inventory_available": "float",

  "avg_selling_price": "float",
  "discount_pct": "float",
  "shipping_fee": "float",

  "marketing_spend": "float",

  "sales_channel_mix": {
    "amazon": "float",
    "website": "float",
    "nykaa": "float",
    "mobile_app": "float"
  },

  "campaign_mix": {
    "search": "float",
    "social": "float",
    "email": "float",
    "affiliate": "float"
  },

  "acquisition_mix": {
    "google": "float",
    "instagram": "float",
    "facebook": "float",
    "organic": "float",
    "referral": "float",
    "email": "float"
  }
}
```

Constraints:

```text
sales_channel_mix sum = 100
campaign_mix sum = 100
acquisition_mix sum = 100
```

---
