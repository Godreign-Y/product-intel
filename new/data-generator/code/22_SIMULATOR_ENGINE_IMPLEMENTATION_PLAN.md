# 22_SIMULATOR_ENGINE_IMPLEMENTATION_PLAN.md

## Objective

Implement a production-quality business world simulator capable of generating realistic business trajectories from:

* Product definitions
* Action schedules
* Business physics definitions

The simulator must support:

1. Forecasting without interventions
2. Forecasting under interventions
3. Multi-action schedules
4. Arbitrary forecast horizons
5. Multiple product archetypes

---

# Inputs

## products.json

Generated by:

```text
20_product_generator.py
```

Contains:

```python
metadata
base_state
behavior_parameters
```

---

## action_schedules.json

Generated by:

```text
21_action_schedule_generator.py
```

Contains:

```python
schedule_id
product_id

events[]
```

# Required Internal Components

The simulator MUST be implemented as modular classes.

Do NOT create one giant script.

---

## Component 1

### ConfigLoader

Purpose:

Load all business physics.

Responsibilities:

```python
load_elasticities()

load_archetype_overrides()

load_market_graph()

load_curve_profiles()
```

Output:

```python
BusinessPhysicsConfig
```

---

## Component 2

### CurveEngine

Purpose:

Calculate effect strength over time.

Input:

```python
elapsed_days
lag_days
peak_days
decay_days
```

Output:

```python
curve_value
```

Range:

```python
0.0 → 1.0
```

Requirements:

* Smooth interpolation
* Continuous output
* No hardcoded day tables

Recommended:

```python
Piecewise Linear Rise

+

Exponential Decay
```

---

## Component 3

### ActionEngine

Purpose:

Determine active interventions.

Input:

```python
schedule
current_day
```

Output:

```python
active_actions
```

Requirements:

Support:

```python
relative_pct

absolute

mix_shift
```

---

## Component 4

### DirectEffectEngine

Purpose:

Apply controllable-state effects.

Input:

```python
current_state

active_actions

curve_values

elasticities

archetype_modifiers
```

Output:

```python
updated_market_state
```

Formula:

```python
effect =
(
delta_pct
*
elasticity
*
curve_multiplier
*
archetype_multiplier
)
```

---

## Component 5

### MarketPropagationEngine

Purpose:

Apply market-state dependencies.

Input:

```python
market_state
```

Output:

```python
propagated_market_state
```

Must implement:

```python
CTR
→ Traffic

Traffic
→ Active Users

Active Users
→ Orders

Conversion
→ Orders

Orders
→ Revenue

Revenue
→ Profit

Orders
→ Retention

Retention
→ LTV
```

Must execute in topological order.

Do NOT create dependency loops.

---

## Component 6

### InteractionEngine

Purpose:

Apply interaction effects.

Examples:

```python
Price + Discount

Marketing + Discount

Marketing + Marketing
```

Interaction Types:

```python
synergy

saturation

suppression

cannibalization
```

Formula:

```python
final_effect =
base_effect
*
interaction_multiplier
```

---

## Component 7

### SeasonalityEngine

Purpose:

Generate recurring demand patterns.

Required:

```python
weekly

monthly

quarterly

annual
```

Implementation:

```python
sin()
cos()
```

based periodic curves.

Output:

```python
seasonality_multiplier
```

Range:

```python
0.8 → 1.2
```

---

## Component 8

### NoiseEngine

Purpose:

Prevent deterministic trajectories.

Implementation:

```python
numpy.random.normal()
```

Suggested:

```python
traffic sigma = 3%

orders sigma = 2%

revenue sigma = 2%

profit sigma = 2%
```

Requirements:

Noise must be reproducible.

Use simulator seed.

---

## Component 9

### ConstraintEngine

Purpose:

Enforce valid states.

Rules:

```python
traffic >= 0

orders >= 0

inventory >= 0

revenue >= 0

conversion_rate in [0,1]

retention_rate in [0,1]
```

Mixes:

```python
sum == 100%
```

---

## Component 10

### StateTransitionEngine

Purpose:

Generate state(t+1).

Pipeline:

```text
Current State

↓

Active Actions

↓

Curve Engine

↓

Direct Effects

↓

Market Propagation

↓

Interactions

↓

Seasonality

↓

Noise

↓

Constraints

↓

Next State
```

Output:

```python
state_t_plus_1
```

---

## Component 11

### TrajectorySimulator

Purpose:

Generate complete trajectories.

Input:

```python

schedule

```

Output:

```python

```

Default:

```python

```

## Component 12

### ParquetStreamWriter

Purpose:

Persist trajectories without exhausting RAM.

Requirements:

Use:

```python

```

Output Folder:

```text
output/

part_000.parquet
part_001.parquet
part_002.parquet
```

Buffer Size:

```python
100000 rows
```

Flush automatically.
